AI STARTER KIT

Use the smallest file that fits the task.

00_agent_minimal.py       Minimal bounded tool-using agent loop
01_structured_output.py   Pydantic validation for model outputs
02_rag_minimal.py         Minimal retrieval + grounded-answer prompt
03_eval_minimal.py        Small classification / agent eval helpers
04_langgraph_minimal.py   Minimal stateful LangGraph workflow
model_adapter.py          One function to connect your available LLM SDK

prompts/
00_build_agent.txt        Prompt Claude Code to build/extend an agent
01_build_rag.txt          Prompt Claude Code to build/extend RAG
02_adapt_starter.txt      Adapt these foundations to a new task
03_debug_ai.txt           Debug AI/agent/RAG failures

Suggested onsite flow:
1. Copy this folder into the working repo.
2. Open prompts/02_adapt_starter.txt.
3. Replace [PATH], [GOAL], [INPUT], [OUTPUT].
4. Let Claude inspect the repo before selecting a starter.
5. Start with plain Python; use LangGraph only if state/branching/resume actually helps.
6. Add eval cases before adding architecture.
