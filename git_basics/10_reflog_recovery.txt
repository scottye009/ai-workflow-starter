REFLOG — RECOVER FROM LOCAL GIT MISTAKES

USE WHEN:
- you accidentally reset
- you rebased and lost sight of a commit
- branch pointer moved
- a commit seems to have disappeared


----------------------------------------
EXAMPLE
----------------------------------------

You accidentally ran:

git reset --hard HEAD~1

Then realize you needed the previous commit.

Run:

git reflog

Example output:

a31bc55 HEAD@{0}: reset: moving to HEAD~1
b72de90 HEAD@{1}: commit: Fix duplicate payment posting retry


The lost commit is:
b72de90


----------------------------------------
RECOVER SAFELY
----------------------------------------

Create a rescue branch:

git switch -c rescue/payment-fix b72de90

Now the commit is reachable again.


RULE:
If something goes wrong:
STOP making more history changes.
Run:
git status
git reflog
git log --oneline --graph --decorate --all
