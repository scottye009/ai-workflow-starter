STASH — TEMPORARILY PUT WORK ASIDE

USE WHEN:
- you have unfinished local changes
- you need to switch branches
- you need to pull something cleanly
- you do not want to commit half-finished work


----------------------------------------
EXAMPLE
----------------------------------------

You are debugging payer policy parsing,
but need to quickly switch to main.

Current changes:
src/policy_parser.py
tests/test_policy_parser.py

Stash them:

git stash push -m "WIP payer parser debugging"

Switch:
git switch main


----------------------------------------
SEE STASHES
----------------------------------------

git stash list

Example:
stash@{0}: On debug/policy-parser: WIP payer parser debugging


----------------------------------------
RESTORE
----------------------------------------

git stash pop

This:
- reapplies changes
- removes stash entry


Or:
git stash apply stash@{0}

This:
- reapplies changes
- keeps stash entry


----------------------------------------
INCLUDE UNTRACKED FILES
----------------------------------------

git stash -u

Useful if you created:
scratch_analysis.py
debug_output.json


----------------------------------------
PREVIEW STASH
----------------------------------------

git stash show -p stash@{0}
