WORKTREE — OPEN A CLEAN COPY WITHOUT DISTURBING CURRENT WORK

VERY USEFUL WHEN:
- current repo has uncommitted changes
- you need a clean branch for an onsite task
- you want two branches open simultaneously


----------------------------------------
SCENARIO
----------------------------------------

Current repo:
/Users/scott/ember-starter

You are working on:
feature/payer-policy-monitor

But need a clean workspace for:
fix/payment-posting-duplicate


Create:

git worktree add ../payment-debug -b fix/payment-posting-duplicate

Now you have:

/Users/scott/ember-starter
/Users/scott/payment-debug


Open the new folder:

cd ../payment-debug


----------------------------------------
LIST WORKTREES
----------------------------------------

git worktree list


----------------------------------------
REMOVE WHEN FINISHED
----------------------------------------

git worktree remove ../payment-debug


----------------------------------------
WHY THIS IS NICE FOR CLAUDE CODE
----------------------------------------

You can point Claude Code at a clean worktree
without risking unrelated changes in your primary workspace.
