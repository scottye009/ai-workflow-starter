FETCH / PULL / UPDATE YOUR BRANCH

USE WHEN:
- main has changed
- teammates pushed updates
- you want latest remote state


----------------------------------------
FETCH FIRST
----------------------------------------

git fetch origin

What it does:
Downloads remote branch information.
Does NOT change your working files.

This is a very safe command.


----------------------------------------
SEE WHAT MAIN HAS THAT YOU DO NOT
----------------------------------------

git log HEAD..origin/main --oneline

Example:
a31bc55 Fix claim status parser
9f12a10 Add new payer mapping


----------------------------------------
UPDATE LOCAL MAIN
----------------------------------------

git switch main
git pull --ff-only

Why --ff-only?
It avoids accidentally creating an unexpected merge commit.


----------------------------------------
BRING MAIN INTO YOUR FEATURE BRANCH
----------------------------------------

Suppose branch:
fix/payment-posting-duplicate

Run:

git switch fix/payment-posting-duplicate
git merge main

Use when:
You want your branch to include latest main.


----------------------------------------
REBASE OPTION
----------------------------------------

git switch fix/payment-posting-duplicate
git rebase main

Rebase rewrites commit history.

Use when:
- team prefers rebase
- branch is your own
- you understand the consequences

For an unfamiliar onsite repo:
Prefer asking the team which workflow they use.
