SET UP A NEW LOCAL FOLDER AS A GIT REPOSITORY

USE THIS WHEN:
You already have a normal local folder, for example:

/Users/yesc/Desktop/ai-workflow-starter

but:

git status

returns:

fatal: not a git repository


==================================================
A. INITIALIZE THE LOCAL REPOSITORY
==================================================

Go into the folder:

cd /Users/yesc/Desktop/ai-workflow-starter

Initialize Git:

git init

Rename the default branch to main:

git branch -M main

Check:

git status


You should now see something like:

On branch main
No commits yet


==================================================
B. ADD A BASIC .gitignore
==================================================

For a Python / AI project:

printf ".DS_Store\n.env\n.venv/\nvenv/\n__pycache__/\n*.pyc\n.ipynb_checkpoints/\n" > .gitignore

Check:

cat .gitignore


==================================================
C. MAKE THE FIRST COMMIT
==================================================

Inspect files:

git status

Stage everything you intentionally want tracked:

git add .

Review staged files:

git status
git diff --staged

Commit:

git commit -m "Initialize AI workflow starter"

Check:

git status


Expected:

On branch main
nothing to commit, working tree clean


==================================================
D. CONNECT TO GITHUB
==================================================

Use this only AFTER creating an empty GitHub repository.

Example GitHub repo:
scottye009/ai-workflow-starter

SSH:

git remote add origin git@github.com:scottye009/ai-workflow-starter.git

Check:

git remote -v

Push:

git push -u origin main


==================================================
E. IF YOU CLONED FROM GITHUB INSTEAD
==================================================

If you created the repo on GitHub first, normally do NOT run git init manually.

Instead:

cd ~/Desktop

git clone git@github.com:scottye009/ai-workflow-starter.git

cd ai-workflow-starter

git status


==================================================
F. HOW TO TELL WHETHER A FOLDER IS ALREADY A GIT REPO
==================================================

Inside the folder:

ls -a

If you see:

.git

then it is already a Git repository.

You can also run:

git rev-parse --show-toplevel


==================================================
G. MOST COMMON STARTER-KIT FLOW
==================================================

Scenario:
You downloaded/copied starter files into:

/Users/yesc/Desktop/ai-workflow-starter

Run:

cd /Users/yesc/Desktop/ai-workflow-starter

git init
git branch -M main

printf ".DS_Store\n.env\n.venv/\nvenv/\n__pycache__/\n*.pyc\n.ipynb_checkpoints/\n" > .gitignore

git status
git add .
git diff --staged
git commit -m "Initialize AI workflow starter"

# After creating the empty GitHub repo:
git remote add origin git@github.com:scottye009/ai-workflow-starter.git
git push -u origin main


==================================================
IMPORTANT
==================================================

git init:
creates Git metadata locally.

git add:
chooses files for the next commit.

git commit:
saves a local version/checkpoint.

git remote add origin:
connects the local repo to GitHub.

git push:
uploads commits to GitHub.
