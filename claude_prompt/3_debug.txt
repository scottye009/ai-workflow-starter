Investigate before changing code.

Trace the workflow from input to output and find the first point where expected and actual behavior diverge.

Classify the likely failure:
- source data
- schema / mapping
- configuration
- business logic
- model / prompt
- tool / API
- state / orchestration
- external system
- output / UI

Return:
1. Reproduction path
2. Evidence
3. First divergence point
4. Most likely root cause
5. Alternative hypotheses
6. Smallest safe fix
7. Validation plan

Do not hide an upstream issue with a downstream patch unless that is clearly the correct design.
