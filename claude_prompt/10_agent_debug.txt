AGENT / WORKFLOW DEBUGGING

REPO: [REPO_PATH]
RUN / TRACE: [TRACE_OR_RUN_ID]
PROBLEM: [QUESTION]

Analyze execution step by step.

For each step identify:
- state entering the step
- decision made
- tool/model called
- arguments
- returned result
- state change
- whether the step was correct

Classify failure:
- wrong routing
- wrong tool selection
- wrong arguments
- bad model output
- bad retrieval/context
- tool failure
- state corruption
- retry/loop problem
- missing validation
- external-system issue

Find the first incorrect step, not just the final symptom.

Return:
1. First incorrect step
2. Evidence
3. Root cause
4. Smallest fix
5. Regression test
